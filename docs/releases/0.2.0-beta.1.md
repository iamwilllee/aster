# v0.2.0-beta.1 — 无支付公开预览版

首个以无支付产品为主的公开预览版本（prerelease）。发布状态与源码下载以 [GitHub Releases](https://github.com/iamwilllee/aster/releases) 为准。

## 支持范围

- showcase：公开展示站，保留双语、主题、页面与 SEO；无需数据库、账号、邮件或支付。
- web-app：D1、邮箱密码账号、验证/重置、会话和资料、私有项目示例、账号导出/注销及显式授权的用户运营后台。默认关闭 Google、支付、图片、内容管理和 AI。
- Aster Skill 与初始化/恢复、按能力检查、已有产品的差异扫描、备份合并、采用记录和保守回退。
- 公开文案交付检查：清理开发横条、测试占位和未采用的示例宣传，保留真实的功能可用状态、试读与私有编辑预览。
- 官网首屏渐次入场、首次滚动出现与轻量悬停；两套主题分别控制节奏，支持减少动态效果、键盘与无脚本降级。
- Sage / Catalog 两套深浅主题、共享控件和页面蓝图。系统字体优先，品牌字体需真实加载；官网与紧凑工具的排版分开。

源码预览额外开启可选图片和内容示例；文字内容无需 R2，图片能力单独配置并验收。Google 按产品需要选择。上述可选能力的代码与本地流程存在，不表示默认开通任何云服务。

## 修复与边界

- 认证未知异常由应用边界接管，避免下层路由输出 SQL 参数；预期错误状态、Cookie 与限流保留，错误日志仍有级别和请求 ID。
- 生产检查遵循能力选择。无支付应用检查页面/API 真正关闭，并通过普通应用的导航、语言及会话流程；不依赖套餐页或支付密钥。
- Stripe / Creem 只保留实验 TEST 代码，不纳入本版正式收款承诺；AI 和用量账本尚未实现。真实邮件/OAuth/R2/Cloudflare 部署按产品独立配置与验收，不提供永久零费用保证。

## 使用与采用

新项目使用 `--profile showcase` 或 `--profile web-app`，也可由 `$aster-new` 整理选择。没有发布到 npm 的初始化包；从本仓库安装锁定依赖后使用附带 CLI/Skill。

已有产品按 UPGRADING.md 增量采用，保留品牌、业务、密钥、数据库和账务。认证改动需合并 auth.server.ts、http.server.ts、日志与路由入口，并验证实际异常、登录/重置/会话；不能只复制 logger。数据库增量迁移必须先审查和应用，不覆盖已经应用的历史 SQL。局部采用不把整个产品冒充已升级到本版本。

从指定版本开始：

```bash
git clone --branch v0.2.0-beta.1 --depth 1 https://github.com/iamwilllee/aster.git
cd aster
pnpm install --frozen-lockfile
pnpm setup
pnpm skill:install
```

Skill 从本地源目录读取代码与规范；已有 Skill 指向另一目录时安装器会保留它。更新源目录不会自动修改其他产品。在目标项目调用 `$aster-new`，要求检查当前底座、增量采用所需改进并独立验收。部署和真实邮件/OAuth/存储接入仍按产品分别执行。

本版本发布的是开源底座源码与 Skill，不替任何产品执行云端部署，不代表真实提供商、商户资格或正式收款已经验收。维护者按 RELEASING.md 核对同一提交的 CI、公开文件、tag 与 Release。
