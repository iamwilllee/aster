# 产品图标设计与接入

[English](en/BRAND-WORKFLOW.md)

在新产品首版开发时执行；已有产品先检查当前品牌，仅在本次涉及品牌/图标时增量采用。命名和页面方向已可推导时直接完成一版，不例行让用户填问卷或从固定样式中选择。已有 Logo、用户偏好和明确参考优先；仅要求业务修复时不顺带重设计。

## 从上下文设计

读取 PROJECT.md、产品名、用户任务、受众、现有页面与品牌素材。先写一句设计依据：图形表达什么、为什么适合这个产品、如何与界面配色呼应。没有既有品牌时由 Agent 自主提出并实现一个方向，在可运行页面中交付可审阅结果；用户要求比较时再提供多个方案。

可选参考是设计词汇，不是必须遵循的模板或配置枚举：

| 方向        | 适用线索                         | 设计关注点                                 |
| ----------- | -------------------------------- | ------------------------------------------ |
| 几何 / 负形 | 精确、结构、轻量工具             | 简单轮廓与独特构形，避免细线堆叠           |
| 字母 / 字标 | 名称有辨识度、品牌已围绕文字建立 | 小图标保留核心字形；不要机械套首字母圆角块 |
| 物象 / 符号 | 产品任务有清晰意象               | 提炼一个核心意象，避免照搬通用功能图标     |
| 有机 / 插画 | 生活、创作、亲和感               | 保留独特轮廓，同时准备小尺寸简化版         |

可融合或另创方向。Sage / Catalog 是页面主题，不限制图标风格，也不要求图标都用绿色。业务控件继续使用 Lucide，产品品牌独立设计。

## 制作与资产

- 简洁标志优先使用可维护的 SVG；插画、质感等位图需求在环境有图像生成能力时使用相应工具/Skill。不可用时用可交付的矢量方向继续，或明确缺项，不声称已经调用生成工具。
- 不依赖外部图标热链。保留可编辑源、素材来源与许可；不把其他产品 Logo 改色当成原创，也不宣称完成商标查重。
- 输出适配导航的图标、favicon 和所需的透明底/深浅背景版本。Apple 主屏图标使用实际导出的 180×180 PNG；只有产出并检查文件后才填配置。PWA 的 192/512 图标和 manifest 按产品是否需要安装能力补充，不能有图就宣称可安装。
- favicon 在 16/32px 要能辨认；小尺寸少细节、足够留白，不塞完整产品名称。Apple 图标保留不透明背景，不预裁系统圆角。按实际产品需要提供横向字标，不为了凑齐资产生成无用变体。

## 接入

`src/config/brand.json` 是运行时资产路径入口：`icon` 为导航图标，`iconDark` 为可选深色替代，`favicon` 为浏览器图标，`appleTouchIcon` 为可选主屏 PNG。路径从 public 根开始；未产出的可选资产保持 null。产品名和描述继续使用 `src/config/site.ts`，主题变量在 styles.css，不重复维护品牌名。

默认 Aster 资源只是初始化占位，不等于生成了新产品品牌。生成器会留下 `brand-identity` 任务和必需本地验收；Agent 实现产品时继续设计、替换引用并清理不再使用的模板品牌素材，保留底座来源记录与许可。不要机械替换内部 starter 标识。只更新 Skill 不会自动替换已有站点。

在 PROJECT.md 记录设计依据、所选方向/推导来源、资产路径、许可和实际验收；在 starter.project.json 的 decisions 中记录 `brand-direction`（basis 为 user/context/default，按实际情况填写），任务与验收证据使用当前产品文件。已有品牌可经实际检查后记为沿用，不强制重画；不继承底座的通过声明。

## 验收与交付

运行 `pnpm brand:check` 检查本地资源路径、文件存在与格式对应；它不能判断美观、原创性、PNG 实际尺寸或模板残留。再执行实际项目的构建、类型和相关浏览器检查。

实际打开首页、登录页和工作台等使用品牌的入口：检查桌面/手机、中英文、浅深主题；导航图标不变形、不挤压文字或改变控件尺寸。检查加载成功和透明背景表现，以 16/32px 实际显示检查 favicon，确认浏览器标签和主屏引用指向新产品。配置主屏图标时检查真实 PNG 尺寸；没有真机验证时明确只完成文件/浏览器验证。

审查资源和引用中的 Aster 模板品牌残留，区分允许保留的开源归属与对访客展示的产品身份。把截图/操作结果记入当前产品的 brand-identity 验收，配置检查通过不能单独作为视觉验收。变更图标或方向后重置受影响证据。若工具/素材阻塞，保留待验收与明确缺项，不能用默认图标冒充完成。发布仍按用户本次授权执行。
